This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Presskit site for "Nebula Circuit" (electronic music artist). A one-page site built with React Router 8 (framework mode, `ssr: false` + prerender), plain CSS Modules and a typed ES/EN dictionary. Deployed to GitHub Pages at `/presskit/`.

## Commands

```bash
pnpm setup        # Install deps (uses --ignore-workspace)
pnpm dev          # Start dev server with HMR
pnpm build        # Production build (output: /build)
pnpm typecheck    # react-router typegen && tsc
pnpm lint         # ESLint
pnpm format       # Prettier
pnpm media        # Regenerate web images/posters/icons + app/content/media.json (needs ffmpeg)
```

For GitHub Pages build: `GITHUB_PAGES=true pnpm build` (sets Vite `base` and router `basename` to `/presskit/`).

A Husky pre-commit hook runs `lint-staged` (prettier + eslint on staged files) and `typecheck` on every commit. `pnpm format:check` is available for CI validation.

## Architecture

### Routing and prerender

Routes live in `app/routes.ts`. The same page file serves both languages via route ids:

- `/` and `/en` → `routes/home/page.tsx` (one page with sections `#bio`, `#music`, `#media`, `#rider`, `#contact`; order in `app/sections/sections.ts`)
- `/rider` and `/en/rider` → `routes/rider/page.tsx` (printable rider, fits one A4 sheet)
- Old per-section URLs (`/intro`, `/technical-rider`, …) → `routes/legacy-redirect.tsx`, mapped in `app/legacy-redirects.ts`

Every path is prerendered to static HTML (`prerender` in `react-router.config.ts`). The `buildEnd` hook runs `scripts/post-build.ts`, which moves the prerendered pages out of `build/client/<basename>/`, turns the SPA fallback into `404.html` and builds the press ZIPs.

`basename` must end with `/` (`/presskit/`): the prerender preview server exits silently otherwise.

React Router's scroll restoration ignores URL hashes in some cases, so the home page re-applies them with `useHashScroll` and the section nav scrolls itself (`components/section-nav`) instead of letting a native hash jump trigger a router navigation.

### Content & i18n

All user-facing text lives in `app/locales/es.json` and `app/locales/en.json` (same shape; `en` is type-checked against `es`). No i18n library: `useT()` returns the dictionary for the language in the URL (`/en/...` → English, otherwise Spanish), `format()` fills `{placeholders}`. Per-page `<title>`/OG/hreflang come from `pageMeta()` in `app/seo.ts`.

### Media

`app/content/media.json` is generated by `scripts/optimize-media.mjs` and holds dimensions, responsive widths and download sizes. Use the helpers in `app/content/media.ts` (`asset()`, `srcSet()`, `fallbackSrc()`) so paths respect the GitHub Pages base.

- Source photos: `public/assets/download-img/nebula-circuit-N.jpg` (also linked as individual HQ downloads)
- Web variants: `public/assets/img/gallery/N-{480,960,1600}.webp`, hero `public/assets/img/hero-*.webp`
- Web videos: `public/assets/video/*.mp4` + generated `.webp` posters; hi-res originals in `public/assets/download-video/` only go into the ZIP
- Icons are keyed out of `design/icon-n.png`, which has a fake checkerboard baked in

To add a photo or video: drop the file in the right folder, run `pnpm media`, commit the output.

### Styling

Plain CSS: global tokens, `@font-face`, reset and print overrides in `app/styles/global.css`; each component has a co-located `style.module.css`. Mobile-first with breakpoints at `600px` (tablet) and `1024px` (desktop). Shared button styles live in `components/button/style.module.css`. Add the global `no-print` class to anything that shouldn't appear on the printed rider.

### Structure

- `app/routes/<name>/page.tsx` + `style.module.css` — pages
- `app/sections/<name>/section.tsx` + `style.module.css` — home page sections (`rider/rider-content.tsx` is shared with the rider page)
- `app/components/` — header, section nav, language switch, buttons, icons (inline SVG), SoundCloud facade
- `app/hooks/` — scroll spy, hash scroll, copy to clipboard

## Code Conventions

- **No semicolons**, single quotes, 2-space indent, 100 char line width, trailing commas (es5) — enforced by Prettier
- Path alias: `@/` maps to `app/` (resolved natively by Vite via `resolve.tsconfigPaths`)
- Node >= 24 required (`.nvmrc` / `.node-version`)
- Package manager: pnpm 10.x
- TypeScript stays on 6.x until `typescript-eslint` supports 7
