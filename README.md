# Nebula Circuit — Presskit

**Nebula Circuit** presskit, a Dark Electro project based in Alcoy (Valencia, Spain)

Live at: **https://nebula-circuit.github.io/presskit/** (English: [/en](https://nebula-circuit.github.io/presskit/en/), printable rider: [/rider](https://nebula-circuit.github.io/presskit/rider/))

## Stack

React Router 8 (prerendered static pages), CSS Modules, ES/EN, deployed to GitHub Pages

## Development

```bash
pnpm install
pnpm dev
```

After adding photos or videos, regenerate the web versions (requires `ffmpeg`):

```bash
pnpm media
```
